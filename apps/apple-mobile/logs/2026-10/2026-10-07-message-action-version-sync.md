# iPhone version sync for Android message action layout

- Synchronized the iPhone app and Live Activity extension version to `1.9`, build `10` in response
  to the Android message action layout update, following the shared native-client versioning rule.
- Apple Watch was not part of this update and remains at version `1.7`, build `8`.
- No iOS source behavior changed or build was run for this version-only sync. The change is local
  and has not been pushed to GitHub.
